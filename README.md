# 🌐 GifsApp 🌐

## 📚 Description 📚
GifsApp es una aplicación web desarrollada con Angular 20 que permite buscar y visualizar gifs de manera dinámica y moderna.
Consume la API pública de Giphy y aplica buenas prácticas de arquitectura frontend, manejo de estado y diseño responsivo.

Este proyecto fue creado con fines educativos y de portfolio, enfocándose en el uso de signals, consumo de APIs y experiencia de usuario.

## 🚀 Features 🚀
- 📋 Listado principal de gifs
- 🔍 Búsqueda de gifs en tiempo real
- 🕒 Historial de búsquedas
- 🧱 Diseño tipo Masonry
- 🌐 Consumo de la API de Giphy
- ⚡ Manejo de estado utilizando Signals
- 📱 Diseño responsivo
